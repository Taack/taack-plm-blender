# Taack PLM workbench for Blender

This addon contains tools to interact with Taack Plm Intranet server app you can find under the https://github.com/Taack/plm

## Installation

Use the Addon Manager, search for Taack PLM

## Description and Usage

After addon installation, set server url and main user in the addon preference window

![preferences](https://raw.githubusercontent.com/Taack/taack-plm-blender/refs/heads/main/blender-prefs.webp)

1. Server URL
2. Username


Connect to the PLM and update blender files:

![connect](https://raw.githubusercontent.com/Taack/taack-plm-blender/refs/heads/main/blender-taack-plm-addons.webp)

1. TaackPLM Panel
2. User password
3. Connect button
4. Upload or sync button
